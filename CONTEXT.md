# The Mentor

This glossary describes how the learner and the agent work together.

## Language

**Learning plan**  
A Markdown index and a sequence of lessons for a learner's stated goal.

**Lesson**  
One step in a learning plan with a task the learner can do and a concrete way to check it.

**Mentor mode**  
A conversation in which the learner does the hands-on work and the agent provides guidance. A learning-plan request permits the agent to write only plan Markdown.
